# 🛍️ تحلیل احساسات کامنت‌های دیجی‌کالا

اپلیکیشن Streamlit برای تشخیص احساس (مثبت / خنثی / منفی) نظرات فارسی کاربران دیجی‌کالا، با ترکیب متن نظر و امتیازی که کاربر به محصول داده است.

## فایل‌های پروژه

| فایل | توضیح |
|---|---|
| `app.py` | اپلیکیشن Streamlit |
| `sentiment_stacking.joblib` | مدل آموزش‌دیده و آماده — **بدون نیاز به اجرای نوت‌بوک** |
| `sentiment_digikala_stacking.ipynb` | نوت‌بوک آموزش مدل (اختیاری، فقط برای بازآموزی یا تغییر مدل) |

اگر فقط می‌خواهید از اپ استفاده کنید، کافی است `app.py` و `sentiment_stacking.joblib` را کنار هم داشته باشید؛ نیازی به اجرای نوت‌بوک یا وجود فایل CSV نیست.

## مدل‌ها

این پروژه از **دو مدل جدا** استفاده می‌کند که نقش‌های متفاوتی دارند:

### ۱. مدل اصلی — طبقه‌بند غیرتولیدی (Non-generative)، نسخهٔ Stacking
پیش‌بینی احساس توسط یک مدل کلاسیک یادگیری ماشین انجام می‌شود، نه یک مدل زبانی تولیدی. ساختار آن:

1. **مدل متنی** (TF-IDF کلمه‌ای + کاراکتری ← Logistic Regression) با cross-validation احتمال‌های out-of-fold می‌سازد.
2. **مدل دوم** (Gradient Boosting) روی «۳ احتمال متنی + Score» آموزش می‌بیند تا تعامل متن و نمره را یاد بگیرد.
3. **وزن هر کلاس** (آستانهٔ تصمیم) روی داده‌ی out-of-fold تنظیم می‌شود تا macro-F1 بیشینه شود (بیشتر برای کلاس خنثی).

خروجی نهایی: احتمال هر سه کلاس (منفی / خنثی / مثبت)، نه فقط یک برچسب.

این مدل سبک، سریع، قابل توضیح و کاملاً آفلاین است — چیزی تولید نمی‌کند، فقط بین سه کلاس از پیش تعریف‌شده انتخاب می‌کند.

### ۲. نظر دوم اختیاری — مدل زبانی سبک (از طریق Ollama)
برای مواردی که مدل اصلی به «منفی بودن» نظر مشکوک است (بالاتر از آستانه‌ی قابل تنظیم)، اپ می‌تواند به‌صورت اختیاری از یک **مدل زبانی کوچک و سبک** (پیش‌فرض: `gemma3:1b` از طریق [Ollama](https://ollama.com)، حدود ۱ میلیارد پارامتر) به‌عنوان نظر دوم استفاده کند.

⚠️ **توجه:** این یک مدل زبانی نسبتاً ضعیف و کم‌حجم است که صرفاً برای اجرای سریع و آفلاین روی سخت‌افزار معمولی انتخاب شده، نه برای دقت بالا. نتیجه‌ی آن را باید یک راهنمای کمکی دید، نه منبع اصلی تصمیم. برای دقت بهتر می‌توانید در تنظیمات، نام یک مدل بزرگ‌تر (مثلاً `gemma3:4b` یا `llama3.1:8b`) را در Ollama جایگزین کنید، یا این بخش را کلاً غیرفعال بگذارید — مدل اصلی بدون آن هم کار می‌کند.

## نصب

```bash
pip install streamlit scikit-learn joblib numpy requests
```

برای فعال کردن نظر دوم (اختیاری):

```bash
# نصب Ollama: https://ollama.com/download
ollama pull gemma3:1b
ollama serve
```

## اجرا

```bash
streamlit run app.py
```

مطمئن شوید `sentiment_stacking.joblib` کنار `app.py` قرار دارد.

## استفاده

1. متن نظر را وارد کنید.
2. امتیازی که کاربر به محصول داده (۰ تا ۱۰۰) را با اسلایدر تنظیم کنید — این عدد دقت پیش‌بینی را به‌طور محسوسی بالا می‌برد.
3. روی «تحلیل کن» بزنید تا احتمال هر سه کلاس و نتیجه‌ی نهایی نمایش داده شود.
4. اگر نظر دوم Ollama فعال و در دسترس باشد و احتمال منفی بالا باشد، توضیح کوتاهی از مدل زبانی هم نمایش داده می‌شود.

اگر Ollama در دسترس نباشد، اپ بدون خطا فقط بر اساس مدل اصلی نتیجه را نشان می‌دهد.

## آموزش مجدد مدل (اختیاری)

اگر می‌خواهید مدل را با داده‌ی خودتان دوباره آموزش دهید، `sentiment_digikala_stacking.ipynb` را باز کنید. این نوت‌بوک انتظار یک فایل `digikala_sentiment.csv` با ستون‌های `Text`، `Score` و `Suggestion` را دارد (نگاشت `Suggestion`: ۱=مثبت، ۲=خنثی، ۳=منفی) و در پایان یک `sentiment_stacking.joblib` جدید می‌سازد.

| خنثی | 0.37 | 0.32 | 0.34 |
| مثبت | 0.90 | 0.92 | 0.91 |
| **Accuracy** | | | **0.81** |
| **Macro F1** | | | **0.65** |
